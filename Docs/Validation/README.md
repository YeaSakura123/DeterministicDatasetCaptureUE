# 验证器来源与像素对照

十分钟批次锁定使用 validator v23，报告中的来源哈希为 `1d6b7e23145e5555b252fa8b71c1d65c5172bcb216941a6e1d0337bf44c2dcde`。其完整主验证器与几何辅助源码保存在 [validator-v23-baseline.zip](validator-v23-baseline.zip)。运行基线需要与当前脚本相同的 Python 依赖。

v24 修正的是可选 Main View/SceneCapture 像素对照的方向评分范围。该对照本来要求 Static 语义测试夹具，旧检查却使用整图误差比较正反 jitter，把透明合成差异也纳入了不透明测试板的方向评分。在安装包实测的 8 个相位中，旧检查有 2 个方向项失败；失败帧之一约 93% 的误差来自透明区域。对应原始输出和旧报告保留。

修正后，方向测试使用全部已知不透明测试板 ID，排除透明风险像素，并要求每类测试板均被覆盖。全图的 5% 归一化平均误差和 20 dB PSNR 门槛保持原值，全图误差仍写入报告。最终包实测 8 相位共 2072/2072 检查通过；不透明测试板在每个相位上使用正确 jitter 的误差都低于反向 jitter。

十分钟批次没有启用这项可选对照，其实际准入报告继续记录锁定的 v23 来源。四地图 32 帧的 v23/v24 对照已确认全部检查结果、统计数值及时间数据准入结果完全一致。v24 的 FG 证据验证与最终安装包检查另有当前版本报告。

这里证明受控不透明表面的取数、曝光和栅格对应。透明区、无效深度及未知自遮挡仍须按风险/有效性掩码处理，不能由完整性 PASS 推断其逐像素监督真值可靠。
